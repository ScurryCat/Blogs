## 五、待决策的两条观察（详见台账 §6.5 / §6.10）

- **O1** 手机里点 INS 标签会**离开手机**（手机 URL 状态表达不了 `tag`）。
  可选：① 扩展手机 URL 契约（动路由约定，需同步 T02 与文档）；② 接受现状。
- **O2** 手机里的 IM 可能**嵌套滚动**（列表自带 520px 上限 + 屏幕也是滚动区）。
  属视觉精修，需图像能力核对后再动。
