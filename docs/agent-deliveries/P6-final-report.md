## 四、本会话修掉的真实缺陷（都有回归测试）

| # | 缺陷 | 影响 |
| --- | --- | --- |
| 1 | 斜屏滑杆「按包围盒取值」 | 斜屏下进度条/音量条中间能拖、两端拖不动 |
| 2 | 图片加载失败无兜底（手记/放课后/殿堂） | 只剩破图，且与「没有图」的文案混为一谈 |
| 3 | 桌面页码存在组件内 | 进 App 再返回总是跳回第一页 |
| 4 | 滚动记忆读写 `window` 而非 `.pw-screen` | **手机里「详情→返回」恢复位置完全没生效** |
| 5 | 换 App 不重置宿主滚动区 | 打开新 App 会继承上一个 App 的滚动位置 |
| 6 | INS 站内链接绕过导航协调器 | 跳转缺少全站过场，与其它 8 个 App 不一致 |
| 7 | IM 草稿存在组件内 | 离开会话草稿即丢；且换角色会串到别人 |
| 8 | 手记列表无滚动记忆 | 打开一条记录再返回，回到顶部 |
| 9 | 手机里的滚动记忆（三重原因：容器错 / 卸载时 DOM 已摘 / 恢复目标被覆盖）| **手机里「详情→返回」恢复位置一直没生效**，单测却全绿；已修好并端到端验证 |
