## 2. 与参考帧的映射边界

参考帧是 3D 地铁隧道（轨道、站台、绿色照明、Awareness Area 指示牌）。
本站没有 3D 场景/隧道素材，用**黄黑警示条 + 荧光绿冷光 + 紫色余光 + 斜向隧道线**
复刻「印象空间 = 地铁隧道」的整体语言，不伪造游戏画面。
