## 3. 关键设计决定

**固定排列之外、但已登记的应用追加到末页，空页跳过。**
理由：任务书要求「排列固定」，但注册表仍是「应用存在」的唯一来源（宿主不加分支）。
两者兼顾：固定 10 个位置不动，新登记应用落在末页，不会被静默隐藏。
副作用是**4 个既有宿主测试原样通过**（它们用自定义注册表注入 demo/other 应用）。
