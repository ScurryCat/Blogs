## 2. 与参考帧的映射边界

参考帧是 P5R 天鹅绒牢房内景（蓝丝绒、冷光、Lavenza 与金色装饰）。
本站没有人物/房间素材，也不做 3D 场景；用**深蓝丝绒条纹 + 冷光 + 金饰线 + 白色登记板**
复刻房间与「登记簿」的整体语言，而不是伪造游戏画面或角色立绘。
