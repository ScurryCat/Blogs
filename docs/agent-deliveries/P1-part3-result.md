## 3. 过程中修掉的两个真问题

1. **无时长时显示 `0:00 / 0:00`**（jsdom 的 `duration === 0` 暴露）—— 会误导成「已到开头」。
   改为 `--:--`，进度条禁用。
2. **迷你栏压住旧站问卷启动器**（T02 套件点不到 `.poll-launcher`，点击被迷你栏按钮拦截）——
   在 `globals.css` 把启动器抬到迷你栏之上（`bottom: var(--mini-h) + 20px`），
   **不修改旧站快照** `styles/legacy/poll.css`。
