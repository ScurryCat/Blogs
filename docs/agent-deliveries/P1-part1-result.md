## 3. 方案与根因（简述，详见 P0-result.md 第 3 节）

- Chrome 对 `matrix()`/`matrix3d()` 序列化形式的命中测试不可靠（连纯仿射也坏），
  且旋转角存在数值雷区（实测 θ≈8.17° 与 θ≈-6.71° 的 skew 链必坏，θ∈[4.26°,6°] 正常）——
  **任何改 CSS 变换的「修法」都会在参数微调下翻盘**，故弃用；
- 最终方案**不依赖 CSS 命中测试**：三标记实测几何 + 卡片级委托命中 + 投影取值。
- 透视屏的视觉四边形与包围盒不一致（包围盒两端不在视觉条上，局部 y 达 ±6~7 个条高）——
  因此**测试必须沿视觉中线取样**，沿包围盒取样会把「测试点选错」误判为实现缺陷。
