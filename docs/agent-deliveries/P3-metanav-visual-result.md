### 1.1 异世界导航整套样式按浅色主题写死在深色站点上

`metanav.module.css` 的卡片、结果面板、输入框、足迹项全部按浅色页面写死
（`rgba(255,255,255,0.72)` 白卡片、`#555` 正文、白底输入框、黑色系的边框/虚线）。
站点是深色底 → 实际效果是**灰白卡片 + 低对比文字**（改前截图
`.dsh/vis2/metanav-palaces-before.png` / `metanav-resolve-before.png` 可见）。
本轮把访客视图改成站点既有红黑白语言，并让管理端输入框在深色页上保持可读。
