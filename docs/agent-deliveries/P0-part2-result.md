1. **P5 头像表 43/50 个 sprite 近黑白（饱和度 < 0.12）** —— 程序化证实这批素材是
   **原版黑白美术**，任务书 §4.2 要求的「原版黑白头像」**素材本身已具备**；
   缺的只是「哪个序号是哪位角色」的核对，**不是素材缺失**。
2. **头像候选从 50 收窄到 12**（近黑白 ∩ 近正方 ∩ 非满幅，边长 91–124px）：
   序号 **3, 4, 5, 12, 19, 20, 24, 25, 27, 31, 35, 36**。
   另有 8 个同条件但只有 18–49px 的小元件（6,7,8,11,46,47,48,49），是符号不是头像。
   → 核对工作量从「50 个里认」变成「**12 个对应 12 位角色**」。

   说明这些元件本身是黑白线稿系，接入时不需再套灰度滤镜。
