### 1.1 放课后此前是「浅色主题样式」写在深色站点上

`leisure.module.css` 的访客卡片按浅色页面写死：卡片 `rgba(255,255,255,0.72)` 白底、
文字 `#444`、边框 `rgba(0,0,0,…)`。站点是深色底 → 实际效果是**灰白卡片 + 对比度极差的文字**
（改前截图 `.dsh/vis2/leisure-game-before.png` 可见）。本轮把访客视图改成深色 P5 主题，
并顺带修掉管理端表单的一个真实问题：`.select/.input/.textarea` 是白底 + `color: inherit`
（继承深色页面的浅色文字）→ 白底白字。现在显式 `color: #0a0a0b`。
