## 4. 过程中被自己的改动绊了一次（值得记）

给放课后封面占位加 `role="img"` + `aria-label` 之后，**放课后 2 个「进度条」测试立刻失败**
（同页进度条本来就用 `role="img"`，多出一个后断言分不清）。
用「临时 `git stash` 收起我的改动再跑」确认是**自己引入**的，改为纯文本占位
（可见文本对屏幕阅读器同样可读），**不放 role**。

教训：可访问性角色不是越多越好，同一视图里重复的 `role` 会破坏既有断言。
