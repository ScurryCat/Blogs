## 3. 与参考帧的剩余差距（不冒充整屏还原通过）

1. **手机外框与手部持机**未复刻（本站是浏览器内手机壳，参考帧是手持特写）；
2. **整屏比例/字体/日期角标**：参考帧左上大日期块、底部 `IM / Next` 按钮为游戏 UI 语言，
   本站保留站点 HUD/宿主返回，不复制游戏操作提示；
3. **消息条排版**：参考帧消息条宽度/倾斜角度是固定画布，本站按 320–430px 手机宽自适应；
4. IM **照片消息**的裁切比例（参考帧大幅偏方）与多图叠放尚未实现；
5. 逐像素对照（尺寸/间距/字体基线）尚未做，因此本项仍标「部分还原」而非验收通过。
