## 3. 关键决定：为什么用 `<details>`

详情菜单用原生 `<details>` 而不是自绘弹层：键盘天然可操作，且**不需要接管 Escape**
—— Escape 已归 `OverlayManager`（手机宿主）统一排队，嵌套接管会把「应用内先回应用层」
的既有语义搞乱。
