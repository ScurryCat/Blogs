## 5. 不要踩的坑（本会话实测）

- **系统代理会骗人**：本机开 Clash 时，Python 3.13 `urllib` 不采用系统代理 ExceptionsList，
  连 127.0.0.1 也走代理 → 验收脚本 502/超时，而 `curl` 正常。脚本已统一 `no_proxy`。
- **8000/8100 是验证前置**：旧站静态预览与 dev API 被误杀会造成 T02 失败、
  多视口「滑杆命中全挂」（音乐不可用→播放器 disabled 的连锁假失败）。
- **dev 与生产构建行为可能不同**：图库灯箱曾在 dev 因 StrictMode + focus-restore 耦合而打不开，
  生产正常；验收以生产构建为准，但 dev 的怪现象要查。
- **Next dev 必须用 `localhost` 访问**（`127.0.0.1` 下 HMR/水合不工作）。
- **隔离栈每次 `up` 会重建数据库**：技能/印象空间种子要手动跑 `app.modules.skills.seed`；
  dev 媒体根在 `/tmp` 下是易失的，媒体 404 先查 `MEDIA_ROOT` 目录。
- 验收脚本可能因**布局变化**假失败（例如 IM 有样式后角色入口被裁剪、新登记应用改变桌面第二页清单），
  先看是不是脚本假设过旧，再怀疑产品回归。
