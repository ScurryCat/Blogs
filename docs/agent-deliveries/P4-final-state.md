## 5. 不要踩的坑（本会话实测）

- **dev 与生产构建行为可能不同**：图库灯箱曾在 dev 因 StrictMode + focus-restore 耦合而打不开，
  生产正常；验收以生产构建为准，但 dev 的怪现象要查。
- **Next dev 必须用 `localhost` 访问**（`127.0.0.1` 下 HMR/水合不工作）。
- 隔离栈每次 `up` 会重建数据库：技能/印象空间种子要手动跑 `app.modules.skills.seed`；
  后端 seed 写入的媒体与 API 的 `MEDIA_ROOT` 不一致会造成「封面 404」假象。
- 验收脚本可能因**布局变化**假失败（例如 IM 有样式后角色入口被裁剪、新登记应用改变桌面第二页清单），
  先看是不是脚本假设过旧，再怀疑产品回归。
