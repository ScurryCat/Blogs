# 怪盗 ch 问卷 HUD 与可复用组件设计

日期：2026-10-15（Asia/Shanghai）

## 已确认的方向

用户选择方案 A：原生 JavaScript + CSS/SVG，还原 Persona 5 实机画面右下角的怪盗网站问卷 HUD，并便于配置新问卷。用户补充要求：字体更贴近原版。

本轮不重写博客框架，不连接后端，不实现账号、全站真实投票或多步骤表单，不自动推送仓库。

## 现状与改动边界

- `assets/js/poll.js` 同时承担固定配置读取、投票计算、DOM 渲染、启动和本地存储。
- 旧外观为米白矩形纸片、黑色圆形 Q、小号百分比；实机参考为黑色斜切底板、白色 Q、细长白框票数条和右侧红色大百分比。
- 原有 `pl-poll-v1` 存储只支持一题，`done` 同时表示关闭和投票。
- 关闭逻辑在定时移除前清空了 `box`，可能遗留 DOM；组件销毁必须明确持有并移除当前节点。
- 站点通过 PJAX 换页，共享脚本只加载一次。默认浮层需要保持单实例，内嵌实例由所属页面销毁。

只调整问卷、其配置、独立样式、必要的资源引用、示例与说明。其他页面功能、BGM 和导航行为保持不变。

## 视觉与字体

### 外观

- 黑色不规则斜切底板，避免通用米白卡片外观。
- 白色 Q 位于左侧并与票数框叠合；Q 作为装饰性 SVG 独立重绘，使用 `aria-hidden`。
- 标题、问题、票数框、百分比与评论按实机参考建立层级和倾角。
- 红色只用于主百分比、进度填充和配置指定的强调文字。
- 原版结果条与网页投票操作分开：未投票时提供明确的两个选项按钮，投票后禁用并标记选择。
- 浮层的关闭按钮可被键盘操作；内嵌模式不显示浮层关闭控件。

### 字体策略

- 中文标题与问题优先复用仓库已有 `Alimama ShuHeiTi`，作为可验证的近似还原，不声称它是原游戏字体。
- 百分比、`ch` 与英文选项优先复用仓库已有 `p5hatty`，对照实际显示效果分别调整字号、字距和倾角。
- 不能以整块统一斜体代替字形校正；百分号与数字使用独立字号及基线。
- 评论优先保证小字号下的可读性，不对每个汉字随机套撕纸贴片。
- 不下载或引入新的商业字体，不修改现有字体文件；保持现有来源说明。
- 字体加载失败时保留明确回退，问卷仍能阅读和操作。

设计预览保存在 `.superpowers/brainstorm/`，不作为生产组件，也不发布为站点资源。

## 配置与调用

采用单题、二选一问卷。选项文字可以自定义，不限于 YES/NO。

配置字段：

| 字段 | 意义 |
| --- | --- |
| `id` | 稳定且唯一的问卷标识；新题使用新 ID |
| `title` | 标题，默认怪盗 ch |
| `question` | 纯文本问题 |
| `questionHighlight` | 可选的强调文字列表 |
| `options` | 两个选项，每项包含稳定的 `value` 与显示 `label` |
| `base` | 各选项的展示基准票数 |
| `main` | 大号百分比对应的选项值 |
| `comment` | 可选评论，含作者、纯文本和强调文字列表 |

默认问卷继续从站点配置启动。旧 `q`、`by` 等字段在默认配置中迁移到新格式；旧富文本字段迁移为纯文本与强调列表，不把配置原文直接插入 HTML。

公开入口为 `PL.poll.create(config, options)`。显示选项包含 `mode`（`floating` 或 `inline`）与 `container`；内嵌模式必须给出容器。

实例提供 `show()`、`close()` 和 `destroy()`。`close()` 负责关闭当前显示，`destroy()` 还需释放监听和计时器。`PL.poll.show()` 保持兼容，用于再次打开默认问卷；默认问卷的 reset 能力保留。

重复显示同一实例不生成重复 DOM。页面卸载时内嵌实例通过现有 `PL.onLeave` 注册销毁；默认浮层不随 PJAX 换页重复初始化。

## 状态与存储

- 存储按问卷 ID 隔离，区分 `seen` 与 `vote`。
- 关闭只记录见过，不增加票数；投票只接受当前配置内的合法选项。
- 一道题只增加一次本地票数。刷新或重复点击不重复累计。
- 不同题目互不影响；对同一题创建第二个实例时，需读取同一份已保存选择。
- 旧 `pl-poll-v1` 记录只迁移到默认问卷，不应用到后来新增的题。
- 默认 reset 清除默认问卷的新旧存储记录，防止旧记录再次迁入；其他题不受影响。
- 存储缺失、无效 JSON、不可用或写入失败时，降级为当前页面内的状态，交互仍可完成。

百分比等于“基准票数 + 本机投出的一票”除以当前总数；总数为零时显示零，不产生 NaN。基准票数必须是有限非负数，非法配置给出清晰错误，不静默产生错误结果。

保留本地展示的说明：界面与辅助技术均可获知这些数字不代表全站真实统计。纯展示模式不发出网络请求。

## 可访问性与响应式

- 问题、选项、百分比均为真实文本；按钮使用原生 `button`。
- 支持 Tab、Enter/Space；Escape 关闭浮层，但不移除内嵌问卷。
- 投票完成的状态通过 `aria-live` 简短提示，不能把关闭动作提示为“已投票”。
- 提供明显的焦点样式，文字强调不能成为理解问题的唯一方式。
- 遵循 `prefers-reduced-motion`；关闭动画结束后移除 DOM，销毁时清除尚未执行的计时器。
- 检查 320、390、768、1280 像素宽度。较长问题允许换行，不以裁切隐藏内容。
- 为 `00.0%`、`07.3%` 和 `100.0%` 留足空间，票数框与数字不得互相覆盖。

## 错误处理

- 缺失 ID、重复选项值、不是两个选项、无效 `main`、无效基准票数属于配置错误，应在创建阶段报告。
- 文本与强调内容按文本渲染，不执行 HTML、脚本或事件属性。
- 对已销毁实例重复销毁保持安全；关闭过程中再次显示不得遗留旧节点。
- 挂载失败不影响博客其他功能，默认自动启动需提供可诊断的错误信息。

## 验证与交付

1. 对投票计算、百分比边界、每题状态隔离、关闭不投票和旧记录迁移做自动化测试。
2. 浏览器验证投票、关闭、再次显示、刷新、键盘操作与内嵌销毁。
3. 验证站内跳转不增加默认问卷实例或全局监听，BGM 与导航保持原有行为。
4. 检查多个实例、不同题目、长问题、最大百分比与窄屏布局。
5. 加载真实字体做截图对照，明确近似还原程度；不能仅凭 CSS 字体声明判定字体已成功加载。
6. 提供独立组件样式、默认问卷迁移、可运行的浮层/内嵌示例和“如何新增一题”的说明。

完成标准：能通过新增一份配置创建第二道独立问卷，无需修改渲染代码；样式采用已确认的 A 方向，字体细化通过用户设计稿审阅。
