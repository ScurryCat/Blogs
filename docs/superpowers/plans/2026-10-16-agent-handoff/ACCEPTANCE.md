# 跨包验收与交付清单

入口：[交接计划](README.md)。各任务卡的功能验收与本清单同时适用。

## 1. 每个包都执行

- [ ] 检查开始时的 Git 状态及基线，不覆盖用户或其他 agent 的修改。
- [ ] 需求有对应测试：先建立会失败的针对性断言，再实现；记录失败原因而不只增加一个永远通过的快照。
- [ ] 类型检查、模块测试、相关数据库约束和构建有真实命令与输出；未运行项单列。
- [ ] 新公开内容在列表、详情、搜索、分享、图片和 AI 读取路径都验证权限。
- [ ] 320 / 390px 与桌面阅读、键盘返回、关闭、焦点、减少动态效果、失败状态可用。
- [ ] 只有实际行为 / 内容才显示图标、计数与成功提示，测试数据不伪装真实履历。
- [ ] 模块退出取消读取与监听；音乐单例及动画规则不变。
- [ ] 不新增生产密钥、绝对本机素材路径、任意 HTML / 脚本执行或未经确认的外部收费调用。
- [ ] 提交本包的 `docs/agent-deliveries/Txx-result.md`，交出需要集成的增量。

## 2. 集成时必须覆盖的矩阵

| 场景 | 预期 | 主责 |
| --- | --- | --- |
| 地图图标 / 出发 / 列表；顶部导航 | 前三者人群，顶部 Joker，不能按当前页面猜测 | T02 / T10 |
| 关闭手机、换 App、换路由，各重复 20 次 | 无重复音频、监听和残留遮罩 | T02 / T10 |
| 手机详情直接 URL、刷新、Back、展开 | 状态一致，关闭直接链接不会意外离站 | T02 + 各 App |
| 旧 post.html 查询和首页 hash | 到正确内容，缺失 slug 真正 404 | T02 / T10 |
| 发布一条图文并在另一浏览器读取 | 同一真实数据，草稿不可见 | T01 / T03 |
| 动态撤回，但照片仍在公开相册 | 图文不可见，仍公开的相册图片可见；提示准确 | T01 / T03 / T06 |
| 同图所有公开引用撤回 | 新匿名媒体请求不可读；原图始终仅管理用途 | T01 / T03 / T05 / T06 |
| 日记 private 或 draft | 标题、正文、图片、日历计数、搜索及 AI 都不泄漏 | T05 / T08 / T10 |
| 殿堂所有文章撤回 | 列表、详情、搜索、匹配、重访均不暴露 | T04 |
| 剧情 → 自由输入 → 回到剧情 | 节点不被模型推进，不重复展示已读开场 | T08 |
| 会话 A 请求 B 的 UUID | 读写都拒绝，不因 UUID 难猜放行 | T08 |
| AI 超时 / 额度耗尽 / 重试 | 预设剧情仍可用，幂等约束有效，成本不被静默隐藏 | T08 |
| 作品 / 技能没有匹配 | 正常空态，不虚构作品或完成度 | T06 / T09 |
| API 重启、DB 不可用、磁盘不足、迁移失败 | 明确未就绪 / 错误，不返回假 ready，不覆盖现有数据 | T01 / T10 |
| 隔离恢复 DB + 媒体 | 数量、引用和核心流程核对，旧会话撤销 | T10 |

原版 UI 的验收保存具体参考帧来源、游戏版本、实际页面截图、对照项与偏差。精灵表不等于完整布局；标题字体近似不写成使用了原版字体。T08 必须区分“原版短信还原”和“原创 INS / AI 输入适配”。

## 3. 发布范围清单

T10 为每次计划发布记录实际选择的任务包，不要求全部功能齐全：

- 当前应用镜像 / 源码版本、schema 版本与配置。
- 本次包含的模块、未启用模块、每个模块的集成测试结果。
- 生产密钥、域名、素材、备份、AI 预算等实际落实情况。
- 恢复点与回退路径；发布失败停止条件。

“代码就绪”“已集成”“已预览验证”“可生产发布”“已部署”是不同状态，报告不得混写。无生产授权就停在就绪报告，不自行上线。

## 4. Agent 交付回复模板

```text
任务：Txx / 名称
状态：implemented_waiting_integration / integrated_verified / blocked（说明具体依赖）
基线：实际 commit + 开始时已有本地修改
完成：本包实际交付的行为
文件：新增 / 修改路径
验证：命令、退出码、通过数量；浏览器截图路径
未验证：缺环境 / 原版参考 / 凭证的具体项目
集成申请：路由、模型、迁移、类型、manifest、媒体引用、依赖
外部影响：是否调用了服务；未获授权的不调用
遗留：限制、错误或必要选择
交付单：docs/agent-deliveries/Txx-result.md
```

该模板中的 `blocked` 是交付描述，不是授权调用产品的 goal 状态工具。
