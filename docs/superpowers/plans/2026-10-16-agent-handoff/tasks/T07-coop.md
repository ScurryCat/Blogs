## 验收

1. 同一友链的修改在 COOP 与其他已接入入口一致；撤回后新公开请求不可见。
2. javascript / data 等地址不能成为可执行外链；纯文本简介不会注入 HTML。
3. 角色联系人不在真实友链列表，旧示例不会被描述成真实朋友。
4. 头像缺失 / 失败、无筛选结果、地址不可用均不破坏列表；不自动删掉朋友。
5. 手机与独立页、键盘与外链点击可用；无共享真实用户私信或假统计。

交付模块与入口接线申请、来源核对清单、API 测试和手机 / 桌面截图。
