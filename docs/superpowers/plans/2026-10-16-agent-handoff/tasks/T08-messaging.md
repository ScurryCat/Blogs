# T08 · 原版 IM 与剧情 / AI 混合角色消息

开始条件：T03 已集成，T01 / T02 基础服务可用。可与 T06 并行。

必读：[共享契约](../SHARED-CONTRACTS.md)、[验收](../ACCEPTANCE.md)、[08 角色消息完整设计](../../../specs/2026-10-16-character-messaging-design.md)、[03 INS](../../../specs/2026-10-16-ins-design.md)、[05 §11](../../../specs/2026-10-16-data-api-design.md)。

## 目标

在 INS 的消息页交付双叶 / 摩尔加纳的一对一会话，预设选项和 AI 输入处于同一段会话，可回到剧情。只有静态界面、只有剧本或只有模拟模型均不是整个任务完成。

模型供应商、凭证、日预算尚未指定；本地可先完成可替换适配层与模拟服务测试，真实 AI 接通 / 计费验收需要协调者落实配置。不得擅自采购、搜索用户密钥或启用收费调用。

## 独占文件

- `apps/api/app/modules/messaging/`：模型、DTO、router、会话服务、剧本引擎、AI 适配、预算与清除。
- `apps/api/app/modules/messaging/stories/`、`apps/api/app/modules/messaging/characters/`：版本化剧本与角色卡；对应 `apps/api/tests/messaging/`。
- `apps/web/features/messaging/` 与测试；`apps/web/app/apps/ins/messages/page.tsx`、`apps/web/app/apps/ins/messages/[character_id]/page.tsx`。
- `docs/design-references/im/`：参考来源、校准记录与可分发的对照证据；`docs/agent-deliveries/T08-result.md`。

不修改 INS 壳、phone registry、auth session、根路由或生成类型。向 T00 交消息页签 / router / 模型与持久预算接线。

## 执行清单

- [ ] 先取得完整的一对一 / 回复选项参考帧，记录游戏版本与来源；本地 sprite 表仅作为头像、SNS 标识与按钮参考。缺完整帧时可以实现结构，但明确视觉还原尚未验收。
- [ ] 在 08 基础上提出 visitor_sessions / conversations / messages、状态版本、幂等 ID、保留期与 API 的契约增量；访客身份与站主会话分开，每次操作校验所有权。
- [ ] 给每个角色写一段可完整走通的原创同人剧情与角色卡。剧本节点和合法选项由确定性引擎持有，AI 不决定下一节点。
- [ ] 先测试“剧情暂停 → 自由输入 → AI 回复 → 回到原节点”的状态机；完成重复点击、旧节点版本、重开和清除行为。
- [ ] 实现原版 IM 风格的角色列表 / 一对一消息 / 选择回复 / 展开输入，角色消息标明同人和 AI。中文正文是真实可读文字，不整屏压缩进手机壳，不用面对面立绘框代替短信。
- [ ] 实现服务端 AI 适配，只传必要会话和当前公开内容；输出纯文本短气泡与允许的内容 ID，验证后显示卡片，点击才导航。没有传图片时不能声称看过照片。
- [ ] 实现访客会话隔离、CSRF / Origin、24 小时保留候选、主动清除、日志脱敏；清除与备份规则交给 T10 核实实际效果。隐私说明区分本站与模型供应商。
- [ ] 实现单会话一在途请求、幂等结果、服务端原子预算预留 / 结算、全站并发、输入 / 输出限制。默认候选每天 20 次 / 输入 1000 码点 / 最多 3 短气泡可以配置；不得仅靠可重置 Cookie 或内存计数承诺限费。
- [ ] 实现超时、断线、关闭面板、额度耗尽与服务禁用；预设剧情仍可使用。返回会话读取已有结果，不自动重发 / 重新收费。
- [ ] T00 接入消息页签后验证 canonical 与手机同一会话；实际供应商配置具备时单独记录真实调用、费用边界和关闭开关，未具备则保持该项未验收。

## 验收证据

| 用例 | 必须证明 |
| --- | --- |
| 自由聊后回到话题 | 原节点 / 选项保留，无重复开场或擅自推进 |
| A 浏览器访问 B 的 conversation ID | 读取、发送、清除都拒绝 |
| 网络重试与重复点击 | 相同幂等请求不重复调用上游；无法撤销的既有成本明确记录 |
| 切换角色后旧响应到达 | 不污染新角色会话 |
| 私密日记 / 草稿 / 其他会话 | 不进入模型输入或内容卡片 |
| 请求预算跨重启、并发请求 | 原子限制有效，不因进程重启清零 |
| 无模型或额度耗尽 | 明确降级，预设剧情可继续，不伪装角色“离线” |
| 清除 / 过期 / 恢复备份 | 正文按实际策略删除，恢复不能悄悄恢复可用旧会话 |
| 原版对照与 390px 软键盘 | 头像、消息层次、选择态有参考；输入和最后消息不被遮住 |

模拟服务测试与真实模型联调分开报告；模型接入不作为 UI 布局正确的证明。公开上线还需要预算配置、供应商说明与 T10 发布检查。

## 不做

不做群聊、语音克隆、主动推送、长期跨设备记忆、真实用户私信、自动角色评论或自动好感度。预设剧情不冒充官方台词，AI 不操纵站点管理操作。

派发：你负责 T08，优先确保原版短信视觉和混合状态机都真实成立。先交可测的剧情与适配层，再按获准配置验证真实 AI；不要用 mock 回复宣称混合聊天全部完成。
