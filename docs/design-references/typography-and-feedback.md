# 字体与共享操作反馈规范（P0 · 素材与视觉基线）

> 对应《P5 怪盗手机 · 第二轮 UI 开发任务书》§2.4 / §8.2。本规范对**本轮所有 App 界面**生效；
> 各 App 的标题大小、叠边、留白仍按各自原版参考单独校准，**不套同一种卡片模板**。

## 1. 字体（沿用现有 token，不新引入字体）

现有 token 定义于 `apps/web/styles/legacy/base.css`（沿用，不修改）：

| token | 栈 | 用途（本轮规范） |
| --- | --- | --- |
| `--f-cjk` | `'Noto Sans SC', 'PingFang SC', 'Hiragino Sans GB', 'Microsoft YaHei', sans-serif` | **中文正文与中文标题**。中文正文必须无衬线 —— 本栈满足任务书 §2.4 |
| `--f-hat` | `'P5Hatty', 'Anton', sans-serif`（`p5hatty.ttf`） | **英文标题 / 短标语 / 装饰词**。字号、字距按对应原作参考校准 |
| `--f-disp` | `'Anton', 'Noto Sans SC', Impact, sans-serif` | 大字号展示（首页/大标题），与正文分界清晰 |
| `--f-mono` | `'JetBrains Mono', ui-monospace, Menlo, monospace` | 时间、编号、状态码等数字信息 |
| `P5Ransom` | `Persona5FanRansom.ttf` | 已有装饰用途，按现状使用，**不用于正文** |

**规则：**

1. 中文正文：`--f-cjk`，正文区域**不做**难以阅读的装饰处理（不加剪贴、斜切、叠边）。
2. 中文标题：高字重（900），**可**局部剪贴、错位与叠边；装饰只落在标题与框架。
3. 英文标题：`--f-hat`，字号与字距按对应原版参考校准（例如横幅式英文缩到小字号 + 大字距）。
4. 照片、作品截图保留**原色与自然比例**；统一灰度、高对比滤镜只允许出现在框架/操作区，不得施加于内容图片。

## 2. 共享操作反馈

| 操作 | 一致含义（本轮全部界面遵守） |
| --- | --- |
| 返回 | 同义：离开当前视图、保留应保留的状态（滚动/草稿/会话/音乐）。视觉与位置随各 App 构图，但行为一致 |
| 确认 | 主行动，高对比强调态；**禁用态**必须可辨识（不是「看起来能点但没反应」） |
| 筛选 | 选中态明确；切换筛选不得丢滚动位置 |
| 焦点 | `:focus-visible` 必须有可见指示；**装饰不得截断焦点指示**（框、剪贴路径不得盖住 outline） |
| 按键提示 | 只显示**当前真正可用**的操作；不可用的不要画出来 |

**尺寸与触控：**

- 触控目标按**实际显示尺寸** ≥ 44px（检查 `getBoundingClientRect()`，**不是**变换前的 CSS 尺寸）。
  沿用既有做法：布局尺寸除以缩放系数（如 `calc(44px / var(--z))`）补偿 `zoom`。
- 按压反馈 80–150ms，不得引起布局位移（用 transform/opacity/filter）。
- `prefers-reduced-motion: reduce` 下全部动效关闭，但**操作仍可完成**（不是隐藏界面）。

## 3. 与命中修复的配合（§3.1 的结论）

斜屏的滑杆等宽控件不能假设「页面横坐标 = 斜屏内部坐标」线性一致。测量结论与修复方向见
《阶段一交付报告》（`docs/agent-deliveries/P0-result.md` 第 3 节）；实现时滑杆的取值计算
必须走屏幕变换的逆映射，或保证命中测试正确后再沿用线性假设。
