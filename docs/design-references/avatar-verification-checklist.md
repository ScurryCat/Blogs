## 3. 核对后怎么用

1. 把上表填完后，按「可用」的 sprite 生成前端资产：
   - 从原图 `.dsh/p0-analysis/p5-profile-pics-NN-*.png` 拷到
     `apps/web/public/assets/legacy/img/avatar/<charId>.png`（**新增目录**，不改旧文件）；
   - 尺寸建议 160×160 内（原 sprite 已 ~110px，直接放大到 128 或保留原尺寸均可，不重采样更好）。
2. 更新 `docs/design-references/icon-mapping.md` 的「共享元件 / IM 黑白头像」行：
   写清「序号 → 角色 → 路径 → 版本 → 许可结论」。
3. 在 `features/messaging/` 里把角色头像 URL 指到新路径，然后**移除**
   `messaging.css` 的 `filter: grayscale(1) contrast(1.45)`（该滤镜是临时手段）。
4. 未获「可用」结论的角色继续用当前头像，**不要为了统一而混用未核对素材**。

## 4. 若无法逐张核对怎么办

优先方案：**只接入已确认且无许可疑义的少量头像**（例如确认 3–5 个），其余角色保持现状 ——
部分接入好过全部用未核对素材。**禁止**按「看起来像谁」推断后直接上线。

### 5.2 识别方法（可复现）

1. 先确认**这套 sprite 就是游戏内 IM/SNS 头像**：本地参考帧
   `persona-dist/media/image/P5R/p5r-sns--4aa5330b1fe6.jpg` 的聊天头像与表内 #35（龙司）
   同一套线条；P5R IM 元件表 `132782-im-assets-cn-jp` 也含同一批头像。
2. 放大人像（PIL LANCZOS 4–6×）逐张比对标志性特征（发型 / 眼镜 / 耳机 / 非人特征）。
   另外用 P5X 的 SNS 图标（本地参考库 `persona-dist/media/image/P5X/snsicon*`）做母题旁证：
   摩尔加纳在 P5X 的 SNS 头像同样是「黑猫头 + 尖耳 + 獠牙咧嘴」。
3. 只接入满足「身份 + 许可（排除明智）」的 sprite；`#20` 与 `#13` 均非明智。
4. 未采用的 10 个候选（3,4,5,12,19,24,25,27,31,35,36 中除 20 外）**保持待填**：
   本任务只缺 Futaba/Morgana 两个角色，其余不为了「填满表」而猜身份。
