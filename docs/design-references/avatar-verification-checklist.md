# 原版头像核对清单（待图像能力复核）

> 给**有图像能力**的复核者（如第三轮 N6 素材负责人）执行的一份可填表清单。
> 背景：任务书 §4.2 要求「使用原版黑白头像，替换目前对彩色立绘施加灰度滤镜的方式」。
>
> 素材本身已确认具备：`92141-profile-pictures.png`（P5 / PS3 / [Spriters Resource 92141](https://www.spriters-resource.com/playstation_3/persona5/asset/92141/)）
> 中 **43/50 个 sprite 饱和度 < 0.12** —— 是原版黑白美术，不是彩色图（程序化统计，见
> `docs/design-references/icon-mapping.md` §4.2）。
>
> **缺的只是「哪个序号是哪位角色」**，以及**许可核对**（第三轮 §5.2 排除明智吾郎）。

## 0. 两条必须同时满足的判据

| 判据 | 说明 |
| --- | --- |
| **身份** | sprite 对应哪位角色 / 是不是头像（本清单要回填的） |
| **许可** | 第三轮 §5.2 **排除明智吾郎**（Goro Akechi / クロウ / Crow / 黑面具）。<br>`persona-assets-excluded.md` 明确提示：**92141 头像表可能含明智头像** —— 若确认含他，**该 sprite 不得接入**，且不因「看起来是别人」而放行。 |

> 未同时满足两条的 sprite **不得接入前端**；宁可继续用现有临时手段（彩色立绘 + 灰度滤镜），
> 也不猜身份、不猜许可。

## 3. 核对后怎么用

1. 把上表填完后，按「可用」的 sprite 生成前端资产：
   - 从原图 `.dsh/p0-analysis/p5-profile-pics-NN-*.png` 拷到
     `apps/web/public/assets/legacy/img/avatar/<charId>.png`（**新增目录**，不改旧文件）；
   - 尺寸建议 160×160 内（原 sprite 已 ~110px，直接放大到 128 或保留原尺寸均可，不重采样更好）。
2. 更新 `docs/design-references/icon-mapping.md` 的「共享元件 / IM 黑白头像」行：
   写清「序号 → 角色 → 路径 → 版本 → 许可结论」。
3. 在 `features/messaging/` 里把角色头像 URL 指到新路径，然后**移除**
   `messaging.css` 的 `filter: grayscale(1) contrast(1.45)`（该滤镜是临时手段）。
4. 未获「可用」结论的角色继续用当前头像，**不要为了统一而混用未核对素材**。

## 4. 若无法逐张核对怎么办

优先方案：**只接入已确认且无许可疑义的少量头像**（例如确认 3–5 个），其余角色保持现状 ——
部分接入好过全部用未核对素材。**禁止**按「看起来像谁」推断后直接上线。
