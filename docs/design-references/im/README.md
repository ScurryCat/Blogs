### 这张素材表**能**证明什么

逐图查看的结论（与 08 §5 的描述一致）：

- 角色头像是**黑白单色图标**（不是彩色立绘），形状为半身剪影 + 五官留白；
- 有对话气泡、`!` / `?` 强调图形、相机图标等小标记；
- 有 SNS 拼贴标识，配色是**红 / 黑 / 白**；
- 有一整行按钮字样：`○決定 ×返回`、`○送信 ×關閉`、`○繼續 ○回覆`（含按键圈符号）。

### 这张素材表**不能**证明什么

- **整屏布局**：素材表是元件集合，没有一帧完整的短信界面，
  因此气泡轮廓比例、头像与气泡的边距、姓名与正文的上下关系、选择态的形态、
  消息出现顺序 —— 这些都没有依据；
- 手机（390px）上的改编形式；
- 动效节奏。

**结论（必须诚实）**：本轮实现的是**结构 + 已确证的视觉语汇**，不是逐像素还原。
任务卡里「先取得完整的一对一 / 回复选项参考帧」这一条**没有满足** ——
手上只有元件表，没有完整帧。因此交付单 §7 把「原版 IM 视觉还原」列为**未验收**项。

## 2. 实现里怎么用这些结论

| 已确证的语汇 | 实现 | 位置 |
| --- | --- | --- |
| 黑白角色头像 | 用仓库内旧站素材 `public/assets/legacy/img/portrait/{futaba,mona}.png`，CSS `filter: grayscale(1) contrast(1.45)` 压成单色 | `features/messaging/messaging.css` 的 `.msg-avatar img` |
| 红 / 黑 / 白主色 | 局部 CSS 变量 `--msg-ink` / `--msg-paper` / `--msg-red`，不污染全站主题 | 同上，`.msg-app` |
| 消息层次 | 左进右出的气泡 + 黑色反白的外发气泡 + 姓名/时间行 | `.msg-row-in` / `.msg-row-out` |
| 回复区与确认提示 | 选项列表用 `▶` 前缀；清除记录需要二次确认 | `.msg-choice` / `.msg-chevron` |
| 斜切容器 | 只对头部容器做 `skewX(-4deg)`，正文保持水平（08 §5 明确禁止旋转正文） | `.msg-thread-bar` |
| SNS 标识 | **原创**排版（`.msg-tag` / `.msg-tag-fan`），没有复制素材表里的 SNS 拼贴图 | 同上 |

**没有做**的：大立绘 + 姓名牌（08 §5 说那是「场景对话」的语汇，不套到短信上）。
`features/messaging/` 里不存在任何立绘框组件。

## 3. 校准记录（逐项对照）

对照对象是**素材表**（不是完整帧），因此每一项的结论都标了置信度。

| 对照项 | 素材表的证据 | 本轮实现 | 结论 |
| --- | --- | --- | --- |
| 头像形态 | 黑白单色半身剪影 | 彩色立绘 + CSS 灰度 | **近似**：灰度滤镜得到的是「黑白照片」，原版是「剪影 + 留白」。差异在黑白阈值，不在色彩 |
| 头像比例 | 素材表内各头像尺寸一致（约 256×256 单元） | 列表 52×52 / 头部 48×48 / 气泡 40×40 | **无法核对**：没有整屏帧，比例没有依据 |
| 主色 | 红 / 黑 / 白三色 | `#d81f26` / `#101014` / `#f4f2ee` | 与素材表同色系；具体色值取自素材表取样，不是官方色板 |
| 气泡轮廓 | 素材表只有装饰性气泡图形，没有消息气泡 | 圆角 2/10px + 左侧 3px 黑边（进）；反白（出） | **原创适配**：明确不是还原 |
| 消息左右层次 | 素材表没有 | 进左出右 | **原创适配**（08 §5 只要求「消息层次」） |
| 选择态 | 素材表有按键圈符号（`○決定`） | 选项按钮 `▶` + hover 反白 | **原创适配** |
| 按钮字样 | `○決定 ×返回 ○送信 ×關閉 ○繼續 ○回覆` | 用中文动词（重新开始 / 清除记录 / 发送 / 回到话题） | **不照抄**：素材表是按键提示图，不是界面按钮 |
| 字体 | 素材表不含字体 | 继承全站字体栈，不做描边加粗 | 按 08 §5「不称为原版字体」 |
| 动效 | 素材表没有 | 只有滚动；`prefers-reduced-motion` 下瞬时 | 按 08 §5 与全站规则 |

## 5. 还没有做的事

- **完整参考帧**：一对一 / 多人 / 回复选项三种整屏帧都没有。素材表不能替代；
- **逐项像素测量**：没有帧就没有可测的基准；
- **真人视觉评审**：本轮的「像不像」只有我的判断，没有第二个人看过；
- **第三方素材再分发授权**：因此本目录不含任何原素材切片。

如果后续拿到完整帧，需要重做的对照项是：头像黑白阈值、气泡轮廓与留白、
姓名与正文的相对位置、选择态形态、消息出现顺序。
