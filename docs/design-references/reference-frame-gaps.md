## 2. 每个缺口要什么

### G1 普通文字消息完整帧

- **必须整屏**：包含手机外壳或至少完整的聊天画面边界，能看出发送方 / 接收方的气泡位置、
  头像位置与尺寸、气泡宽度比例、行距、时间戳位置。
- 至少 **2 条会话往返**（对方→我方→对方），才能判断左右对齐与间距。
- 版本标注到 **P5 或 P5R**（两者 IM 布局有差异，不能混用）。
- 若来自视频：记录**视频链接 + 时间点**。
- **不接受**：只有气泡元件的裁剪图、只有头像的图、截图里带其他 UI 遮挡的半屏。

### G2 回复选择完整帧

- 必须显示**回复选项列表**（2 个以上选项）+ 输入区域，能看出选项的选中态、禁用态与排列方式。
- 需要能判断：选项是叠加在聊天上还是替换输入区、选中时的反色/描边方式、多选项时的间距。
- 版本标注同上。

### G3 异世界导航经典红眼图标

- **红眼 + 星形瞳孔 + 黑色外刺**的完整图标（任务书 §2.3 点名）。
- 需要**独立可裁切的图**（不是混在界面截图角落的小图），且能确认是 **P5 原版**而非 P5R/P5X 变体。
- 可追溯来源优先级：官方素材站（Spriters Resource 等）> 官方设定集扫描 > 可核实出处的截图。
  Wiki 页面（如 [Megaten Wiki](https://megatenwiki.com/wiki/Metaverse_Navigator)）只能作为**线索**，
  需继续定位其引用的原图。

### G4 图片消息帧来源核实

- 已有 `p5r-sns--4aa5330b1fe6.jpg`（本地截图，167 KB）—— 内容可用，但**原始发布 URL 未核实**。
- 补：找到该图出处并记录；找不到则在映射表标注「来源不明」，**不补写推测 URL**。

## 3. 补齐后的回填要求

补到参考后，在 `docs/design-references/icon-mapping.md` 的「参考帧清单」表里：

| 字段 | 要求 |
| --- | --- |
| 位置 | 本地路径（参考库，只读） |
| 游戏版本 | P5 / P5R / P5X，**分开记**，不用相近名称替代 |
| 语言 | JPN / CN-JP / ENG |
| 来源 | 素材站页面 URL；视频则给链接 + 时间点 |
| 用途 | 一句话说明它证明哪一项布局 |

## 4. 验收口径（防止「看起来像」就宣布完成）

- 有参考帧 + 有**同状态**的实现截图（同视口）才能勾「还原完成」；
- 只有元件表、没有整屏参考 → 该状态只能勾「结构适配」，**不能勾还原**；
- 参考帧存在但实现截图缺失 → 同样不能勾。
