# 转场矢量数据的生成工具

`assets/js/curtain-data.js` 不是手写的，是这两个脚本从源片里量出来的。
改形状精度、帧号、时间轴都改 `gen.py`，然后重跑；**不要手改数据文件**。

```bash
# 1) 从源片抽帧（源片是 640×360 h264 29.97fps 61 帧）
ffmpeg -i 过场joker拉下帷幕.mp4 frames/f%03d.png

# 2) 生成数据
python3 tools/curtain/gen.py frames assets/js/curtain-data.js
```

## 管线（以及为什么这么做）

| 步骤 | 做法 | 为什么 |
| --- | --- | --- |
| 取形状 | 高斯模糊成软场，在 0.5 等值面上做带插值的 marching squares | 直接对二值掩膜取轮廓得到的是像素阶梯，放大到 1440 宽就是锯齿 |
| 重采样 | 按弧长重采样成固定点数（剪影 192、波浪 96） | 相邻帧点数一致才能做顶点插值（形变） |
| 白色细节 | 按周长自适应点数；细长条（速度线）改用**描边**（中心线 + 线宽）存 | 1–2px 的细线用闭合轮廓表示，重采样会把它抹掉 |
| 编码 | 0.2px 量化 + 沿轮廓 delta + 每 16 点重新绝对定位 | 纯 delta 会随机游走漂移；有符号 36 进制文本可读、可 diff、gzip 友好 |
| 时间轴 | 逐段用源片帧号标定，黑场（21–39 帧）压缩 | 保留编排的同时把 2.04s 压到 1.18s |

## 精度（脚本每次运行都会打印）

与源帧掩膜的 IoU：剪影 min 0.962 / 均 0.990，波浪 min 0.942 / 均 0.980，
白色成块 0.83。1–2px 的抗锯齿细线落在 IoU 的度量噪声地板上（1.5px 线宽 ±0.5px
就是 50% 面积差），那部分靠 `curtain.js` 的 `seek()` 出图目视验收。

运行时用 `PL.curtain.debug()` 看坐标映射，用 `PL.curtain.seek(ms)` 定格任意时刻。
